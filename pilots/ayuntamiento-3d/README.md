Pixels inspected. Photo is historical, not a current site survey. Only this CC0 photo supplies facade details; other candidate images were not used.

Identity / architecture cross-check: https://www.turismoenalbacete.com/es/140/318/10-MUSEO-MUNICIPAL.html . Text only, no photograph copied. Catastro 9371110WJ9197A, front edge (161.2,-60.6) to (178.8,-70.4) in existing local coordinates, width20.14m. OSM independently names this parcel Museo Municipal (Q17187008).

Visible features reproduced in simplified geometry: two upper windows and two lower grilles each side; center door and balcony; square clock tower with front/right clocks, shield outline, cornice, balustrade and stepped parapets. Floral carving, heraldry and lettering are not reproduced. Clock hands are a static artistic pose, not live time. Depths, heights, camera and relief dimensions estimated. Rear/side facade not reconstructed. The existing cadastral masses remain behind the front, with front body height adjusted to11.2m by photo proportions. No generic side windows added.

Run python pilots/ayuntamiento-3d/build.py then python src/build_zone.py. Model is an original geometric interpretation with own materials/illumination, not pasted photo texture. No Google assets. No source photograph in deployment.
