# Bounded transformed source data

`zone-building-parts.json` holds1362normalized Catastro INSPIRE building-part records used by the bounded3Dzone. Snapshot source downloaded16November2026: https://www.catastro.hacienda.gob.es/INSPIRE/Buildings/02/02900-ALBACETE/A.ES.SDGC.BU.02900.zip . Attribution: Dirección General del Catastro. Conditions: https://www.catastro.hacienda.gob.es/webinspire/documentos/Licencia.pdf . Geometric source only, not address/owner data.

Adaptation: `src/parse_bu.py` extracted the exterior ring and all119interior rings in85features, normalized it to local EPSG:25830 offsets, rounded coordinates to0.1m, and retained building-part ID, floors/use/area. Then selected mean-vertex x[-300,250],abs(y)<=250,area>=18. The prior parser discarded interior rings; the corrected parser preserves them and the bounded snapshot was repaired directly from original GML. All1362matched source features had one exterior ring; more complex future source geometries need a new audit. Roof regression tests check these transformed input rings, not an independent current survey. The119source rings include one in an excluded/replaced landmark mass;118rings are used by the1345context roof checks. Holes may expose lower cadastral parts, not necessarily ground or open sky. Source fields are not surveyed heights. Unknown floors remain unknown.

OSM extract remains in `zona-catedral/osm-source.json`, attribution/ODbL in published sources. Coordinate conversion uses `src/local_frame.py`, EPSG:25830 minus the original Catastro origin defined in `src/parse_bu.py`. That origin is retained to preserve existing handcrafted registrations. LiDAR roof samples and their license/provenance are in `pilots/teatro-3d/`.
